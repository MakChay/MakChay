## 🔬 Research & Academic Interests

My academic interests focus on applying computing techniques to meaningful problems.

### Comparative Machine Learning for Student Performance Prediction

My Honours research explores a comparative evaluation of supervised machine learning algorithms for predicting student academic performance using the UCI Student Performance dataset.

**Algorithms under investigation:**
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

**Research interests:**

`Model Evaluation` · `Educational Data Mining` · `Classification` · `Explainable AI` · `Responsible Machine Learning`

The goal is to compare model performance systematically and investigate how predictive insights can support better-informed educational interventions.
